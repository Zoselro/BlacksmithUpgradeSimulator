기존에는 GameManager의 내부 변수로
 게임 데이터인 골드,방문수,성공횟수,실패 횟수 등 이러한 게임 데이터를 관리를 했지만,
이를 GameDataManager를 통해 CSV에 저장하도록 변경을 하여,
저장되어있는 데이터를 불러옴으로써 게임을 껏다켜도 1일차 1명부터 시작하는게 아닌,
저장되어있는 데이터를 통해 게임을 끄기 전의 데이터를 불러와서 이어서 게임을 진행할 수 있도록 변경

게임을 껐다 켰을 때 단순히 데이터만 불러오는게 아닌
게임을 어느 단계에서 종료했는지 판단할 필요가 있다고 생각하여

강화전, 강화진행중, 강화끝 이 세 단계로 분류를 하여
강화 전과 강화 진행중일 때 게임을 끄면 이전까지의 게임 데이터를 불러오는 방식으로 구현을 하였고,
강화 끝났을 때 게임을 끄게 되면 현재 끈 시점에서 골드량 증가 및 성공,실패 횟수를 반영하도록
구현을 하였음.

그리고 마지막 NPC가 8명째 방문하고 강화가 끝난 시점에서 게임을 종료하고 키면
게임을 켰을 때 바로 정산 애니메이션으로 가도록 구현을 하였음.



-----------


게임 데이터 저장 및 이어하기 기능

기존에는 게임 진행에 필요한 골드, 방문자 수, 성공·실패 횟수 등의 데이터를 게임 내부에서만 관리하고 있었습니다.

이 방식에서는 게임을 종료하면 해당 데이터가 사라지기 때문에, 게임을 다시 실행할 경우 항상 처음부터 게임을 시작해야 하는 문제가 있었습니다.

이를 개선하기 위해 게임 데이터를 별도의 저장 파일(CSV)에 기록하도록 변경했습니다.

이제 게임을 종료하더라도 현재까지의 게임 진행 상황과 보유 골드, 방문자 수, 강화 결과 등의 데이터를 저장하고, 게임을 다시 실행하면 저장된 데이터를 불러와 게임을 종료하기 직전의 진행 상황에서 이어서 플레이할 수 있도록 구현했습니다.

---------------

게임 종료 시점에 따른 데이터 처리

단순히 데이터를 저장하는 것뿐만 아니라, 플레이어가 게임을 종료한 시점이 게임 진행의 어느 단계인지 판단할 수 있도록 했습니다.

강화 과정을 크게 다음 3단계로 구분했습니다.

강화 전
강화 진행 중
강화 완료

이를 기준으로 게임을 다시 실행했을 때 데이터를 다르게 처리하도록 구현했습니다.

1. 강화 전 또는 강화 진행 중 게임 종료

아직 해당 손님의 강화가 정상적으로 완료되지 않은 상태이기 때문에, 게임을 종료하기 직전 진행했던 강화 결과를 그대로 인정하지 않습니다.

따라서 해당 손님의 강화가 시작되기 전 저장해 둔 데이터를 다시 불러와 이전 상태로 복구합니다.

예를 들어,

골드 1,000 → 강화 진행 → 게임 종료

라면 다시 게임을 실행했을 때 강화 이전의 골드와 성공·실패 횟수로 복구됩니다.

이를 통해 게임 진행 중 강화를 완료하지 않은 상태에서 종료하더라도 데이터가 비정상적으로 반영되는 것을 방지했습니다.

2. 강화 완료 후 게임 종료

강화가 정상적으로 완료된 상태라면 해당 강화 결과를 정상적인 게임 진행으로 인정합니다.

따라서 게임을 다시 실행했을 때

강화에 사용된 골드
강화 성공 횟수
강화 대성공 횟수
강화 실패 횟수
방문자 진행 상황

등을 강화가 완료된 시점의 데이터로 유지하도록 구현했습니다.

즉, 강화가 끝난 뒤 게임을 종료하더라도 해당 강화 결과가 사라지지 않고 정상적으로 다음 손님을 받을 수 있도록 이어집니다.

마지막 8번째 손님 처리

하루에 총 8명의 NPC가 방문하도록 되어 있기 때문에, 마지막 8번째 NPC의 강화까지 완료한 상태에서 게임을 종료하는 경우도 별도로 처리했습니다.

예를 들어,

8번째 손님 방문 → 강화 완료 → 게임 종료

후 게임을 다시 실행하면 일반적인 손님 대화 화면으로 돌아가는 것이 아니라, 해당 날짜의 모든 손님 처리가 완료된 것으로 판단하여 바로 정산 화면으로 이동하도록 구현했습니다.

따라서 플레이어가 게임을 종료했다가 다시 실행하더라도 8번째 손님까지 진행한 기록이 유지되고, 해당 날짜의 정산 단계부터 자연스럽게 이어서 플레이할 수 있습니다.
